Getting started

Setup is four steps, and the dashboard shows them as a checklist on the Live tab:

  1. Add a camera (a browser, or a computer or Raspberry Pi).
  2. Draw the couch on the live picture.
  3. Test the alarm.
  4. Connect Telegram (optional, for alerts on your phone).

Nothing counts as “on the couch” until you draw the zone, so step 2 matters.

Use a browser as the camera

The easiest start, with nothing to install. On the device facing the couch (a laptop, tablet or phone):

  1. Open the dashboard and go to Devices.
  2. Under Use this device as a camera, give it a name and press Start camera here.
  3. Allow the camera when the browser asks.

Keep the tab open, the screen awake and the device plugged in. A browser camera needs an https address and internet the first time, to download the detection model.

Use a computer or Raspberry Pi

A small program, the agent, runs next to the camera and keeps running in the background. In the dashboard open Devices, add a camera and copy the command it shows.

Linux and Raspberry Pi OS

Run the command on the Pi or computer. It looks like this:

curl -fsSL https://YOUR-SERVER/install.sh | bash -s -- --server https://YOUR-SERVER --token YOUR-TOKEN

It installs what it needs, downloads the detection model, and sets the agent up as a service that starts at boot, restarts if it stops, and updates itself each time it starts. Add --pi for the ribbon-cable Raspberry Pi camera (a USB webcam does not need it). It takes a few minutes on a Pi. You can read the script at /install.sh before running it.

Check on it with journalctl -u dog-free-couch -f. The camera shows as online in the dashboard within a minute.

Windows and macOS

There is no installer yet. You need Python 3.9 or newer and git. In a terminal: 

git clone https://github.com/RavivGilady/dog-free-couch.git
cd dog-free-couch
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python download_model.py
python agent.py --server https://YOUR-SERVER --token YOUR-TOKEN

The agent stops when you close that terminal, and it does not update itself. Keep the computer awake while it watches.

Draw the couch zone

On the Live tab press Draw couch zone and click the couch's corners on the picture, going around it. Drag a corner to move it; double-click to remove it. The slider sets how much of the dog has to be inside the zone before it counts. Press Save zone; the camera picks it up in a few seconds.

If you move the camera, redraw the zone.

Alarm sound

Press Test alarm on camera on the Live tab. The sound plays from the device running the camera, not from the browser you are using. On the Sound tab you can choose a built-in siren or record your own voice; many dogs react better to that. In Settings you can make it repeat while the dog stays on the couch.

Telegram alerts

  1. In Telegram message @BotFather, send /newbot and follow the steps. It gives you a bot token.
  2. Open your new bot and send it any message.
  3. In a browser open https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates and find "chat":{"id": ...}. That number is your chat id.
  4. In the dashboard open Settings → Telegram, paste both, tick Enabled, press Save, then Test connection.

Troubleshooting

The camera says Offline

  • Browser camera: the tab must be open and running. Open the dashboard on that device and press Start camera here.
  • Agent: it is not running or cannot reach the server. On a Pi run sudo systemctl status dog-free-couch; on other computers check that the terminal is still open.
  • If you pressed New token for the camera, the old token no longer works. Run the new command the dashboard showed.

The picture is grey, frozen or says “no signal”

The camera is found but is not delivering a picture. Common causes:

  • Another app (a video call, the Camera app) is using the camera. Close it, then restart the agent or browser camera.
  • The computer has more than one camera (a built-in one, an infrared Windows Hello camera, a virtual camera) and the wrong one was chosen. On the agent computer run python list_cameras.py. It lists the cameras by name and previews each; pick the one with a live picture. In a browser camera, choose another one from the Camera list.
  • On Windows, the default way of opening the camera sometimes returns a frozen placeholder image. list_cameras.py also tests that and sets backend_api: dshow when it helps.
  • On a Raspberry Pi with the ribbon camera, install with --pi and check the cable is seated firmly.
  • Browser camera: check the browser has permission for the camera (the camera icon in the address bar).

The dog is on the couch but there is no alert

  • Check that a couch zone is drawn and covers where the dog sits.
  • Lower the slider so less of the dog must be inside the zone.
  • The picture needs light and the dog needs to be clearly visible.
  • The Live tab shows Dogs in frame. If it stays at 0 the dog is not being detected; try a different camera angle.

I get alerts but hear no alarm

  • The alarm plays on the camera's device. Check its volume and that Play sound is ticked in Settings.
  • Browser camera: browsers allow sound only after a click, so press Start camera here and leave the tab open.

Telegram says it failed

  • You must send your bot a message first, or it cannot message you.
  • Check the token and chat id for typos; the chat id is a number.
